# Sharing Clips

**What You'll Learn:**
- Generate public share links
- Download clips for posting
- Share with team members

---

## Overview

Cuttr makes it easy to share your clips with clients, team members, or directly to social media.

---

## Share Links

### Generate a Public Link

1. Open your clip
2. Click **"Share"** button
3. Toggle **"Public Link"** on
4. Copy the link

### Link Features

| Feature | Description |
|---------|-------------|
| **Instant access** | No login required |
| **Preview player** | Viewers can watch in browser |
| **Download option** | Optional for viewers |
| **Link expiration** | Set time limit (optional) |

### Disabling a Link

1. Open clip settings
2. Toggle **"Public Link"** off
3. Link immediately stops working

---

## Downloading

### Download Formats

| Format | Best For |
|--------|----------|
| **MP4** | Universal compatibility |
| **MOV** | Apple ecosystem |

### Download Steps

1. Open your clip
2. Click **"Download"** button
3. Choose format
4. File saves to your device

---

## Team Sharing

If you're on a team plan:

- All team members see shared clips
- Move clips to shared folders
- Control access with permissions

---

## Pro Tips

1. **Use links for client review** - Easy approval workflow
2. **Download for posting** - Direct upload to platforms
3. **Set expiration for sensitive content**
4. **Organize before sharing** - Clean up names and folders
