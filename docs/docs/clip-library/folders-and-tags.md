# Folders & Tags

**What You'll Learn:**
- Create and manage folders
- Use tags for flexible organization
- Build an efficient system

---

## Overview

Folders and tags help you organize clips as your library grows. Use folders for hierarchical organization and tags for cross-cutting categories.

---

## Folders

### Creating Folders

1. Click **"New Folder"** in the sidebar
2. Enter folder name
3. Optional: Choose a color
4. Click **"Create"**

### Folder Hierarchy

Create nested folders:
- Client A
  - Campaign 1
  - Campaign 2
- Client B

### Moving Clips to Folders

**Single clip:**
1. Right-click the clip
2. Select **"Move to Folder"**
3. Choose destination

**Multiple clips:**
1. Select clips
2. Click **"Move"** in toolbar
3. Choose folder

---

## Tags

### Creating Tags

1. Click **"Tags"** in sidebar
2. Click **"New Tag"**
3. Enter name and choose color
4. Save

### Suggested Tag System

| Category | Example Tags |
|----------|--------------|
| **Status** | Draft, Ready, Published |
| **Platform** | TikTok, Reels, Shorts |
| **Content Type** | Tutorial, Testimonial, Hook |
| **Performance** | Top Performer, Testing |

### Applying Tags

1. Select clip(s)
2. Click **"Tag"** button
3. Choose one or more tags

---

## Filtering by Folder/Tag

### Folder Filter

Click any folder in sidebar to see only its contents.

### Tag Filter

1. Click **"Filter"** button
2. Select tags to include
3. Clips matching ANY selected tag appear

---

## Pro Tips

1. **Start simple** - Don't over-organize early
2. **Use colors** - Visual distinction helps
3. **Combine both** - Folders for structure, tags for attributes
4. **Clean up regularly** - Remove unused tags/folders
