# Editing Clips

**What You'll Learn:**
- Edit captions and timing
- Modify text overlays
- Make adjustments after saving

---

## Overview

Already saved a clip? You can still make changes. The clip editor lets you refine captions, overlays, and more.

---

## Opening the Editor

1. Find your clip in the library
2. Click on it to open
3. Click **"Edit"** button
4. Editor opens with your clip

---

## What You Can Edit

### Captions

| Action | How |
|--------|-----|
| Fix typos | Click caption, edit text |
| Adjust timing | Drag caption boundaries |
| Change style | Use style panel on right |
| Delete words | Select and delete |

### Text Overlays

| Action | How |
|--------|-----|
| Edit text | Click overlay, type new text |
| Reposition | Drag to new location |
| Restyle | Use formatting options |
| Delete | Select and press Delete |

### Clip Boundaries

- Adjust in/out points
- Trim start or end
- Fine-tune hook length

---

## Saving Edits

- Changes auto-save as you work
- Click **"Done"** when finished
- New version replaces the old

:::note
Editing is free and doesn't use additional credits.
:::

---

## Pro Tips

1. **Preview before finalizing** - Watch the full clip
2. **Check on mobile** - Text may need resizing
3. **Keep captions concise** - Split long sentences
4. **Test audio sync** - Ensure captions match speech
