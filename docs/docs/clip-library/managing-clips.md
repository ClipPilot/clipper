# Managing Clips

📌 **What You'll Learn:**
- Navigate your clip library
- Search and filter clips
- Perform bulk actions

---

## 🎯 Overview

Your Clip Library is the central hub for all your generated content. Find, organize, and manage every clip you've created.

---

## 📍 Accessing the Library

1. Click **"Clips"** in the sidebar
2. View all your saved clips
3. Use filters to narrow down

---

## 🔍 Finding Clips

### Search

Type in the search bar to find clips by:
- Clip name
- Source video name
- Tags

### Filters

| Filter | Options |
|--------|---------|
| **Source** | AI Clipping, UGC, Face Swap, Ad Clone |
| **Date** | Today, This Week, This Month, Custom |
| **Status** | Processing, Ready, Failed |
| **Tags** | Your custom tags |

### Views

| View | Best For |
|------|----------|
| **Grid** | Visual browsing |
| **List** | Quick scanning, bulk actions |

---

## ⚡ Clip Actions

### Single Clip

Click on a clip to:
- ▶️ Preview
- ✏️ Edit (captions, overlays)
- 📁 Move to folder
- 🏷️ Add tags
- 🔗 Get share link
- ⬇️ Download
- 🗑️ Delete

### Bulk Actions

1. Select multiple clips (checkbox or Shift+click)
2. Choose action from toolbar:
   - Move to folder
   - Add tags
   - Delete

---

## 💡 Pro Tips

1. **Name clips descriptively** - Makes searching easier
2. **Use folders** - Group by project or client
3. **Tag consistently** - Create a tagging system
4. **Archive old clips** - Keep library clean
