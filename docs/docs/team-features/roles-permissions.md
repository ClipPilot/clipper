# Roles & Permissions

📌 **What You'll Learn:**
- Available team roles
- What each role can do
- Changing member roles

---

## 🎯 Overview

Roles control what team members can access and modify. Assign roles based on responsibilities.

---

## 👤 Available Roles

### Owner

The team creator with full control.

| Permission | Access |
|------------|--------|
| Manage billing | ✅ |
| Delete team | ✅ |
| Manage all members | ✅ |
| All content actions | ✅ |

*Note: Only one Owner per team.*

### Manager

Trusted members with administrative access.

| Permission | Access |
|------------|--------|
| Invite members | ✅ |
| Remove members | ✅ |
| Manage content | ✅ |
| View usage | ✅ |
| Manage billing | ❌ |

### Member

Standard team members.

| Permission | Access |
|------------|--------|
| Create content | ✅ |
| Edit own content | ✅ |
| View shared content | ✅ |
| Invite members | ❌ |
| Manage team | ❌ |

---

## 🔄 Changing Roles

### How to Change

1. Go to **Settings → Team → Members**
2. Find the member
3. Click the role dropdown
4. Select new role
5. Confirm change

### Restrictions

- Owner can change anyone's role
- Managers can change Members only
- Cannot demote yourself below Owner (if you're the Owner)

## 💡 Pro Tips

1. **Limit Managers** - Only trusted team leads
2. **Start as Member** - Promote as needed
3. **Regular reviews** - Audit roles quarterly
