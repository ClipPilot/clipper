# Roles & Permissions

**What You'll Learn:**
- Available team roles
- What each role can do
- Changing member roles

---

## Overview

Roles control what team members can access and modify. Assign roles based on responsibilities.

---

## Available Roles

### Owner

The team creator with full control.

| Permission | Access |
|------------|--------|
| Manage billing | Yes |
| Delete team | Yes |
| Manage all members | Yes |
| All content actions | Yes |

*Note: Only one Owner per team.*

### Manager

Trusted members with administrative access.

| Permission | Access |
|------------|--------|
| Invite members | Yes |
| Remove members | Yes |
| Manage content | Yes |
| View usage | Yes |
| Manage billing | No |

### Member

Standard team members.

| Permission | Access |
|------------|--------|
| Create content | Yes |
| Edit own content | Yes |
| View shared content | Yes |
| Invite members | No |
| Manage team | No |

---

## Changing Roles

### How to Change

1. Go to **Settings → Team → Members**
2. Find the member
3. Click the role dropdown
4. Select new role
5. Confirm change

### Restrictions

- Owner can change anyone's role
- Managers can change Members only
- Cannot demote yourself below Owner (if you're the Owner)

| Delete any clip | Yes | Yes | No |
| Invite members | Yes | Yes | No |
| Remove members | Yes | Yes | No |
| Manage billing | Yes | No | No |
| Delete team | Yes | No | No |

---

## Pro Tips

1. **Limit Managers** - Only trusted team leads
2. **Start as Member** - Promote as needed
3. **Regular reviews** - Audit roles quarterly
