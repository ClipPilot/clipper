## 🆓 Free Plan

**Perfect for:** Testing Cuttr before committing.

### Includes
- 10 clip saves per month
- Basic AI clipping features
- Standard caption styles

### Limitations
- No UGC Studio features
- No Face Swap or Ad Clone
- Single user only

---

## 💜 Studio Plan

**Most popular for:** Content creators and small teams.

### Includes
- **500 clips/month**
- Unlimited AI generations
- Full UGC Studio access
- Face Swap (5 credits each)
- Ad Clone feature
- AI Video Creator
- 3 team members

---

## 🚀 Scale Plan

**Built for:** Agencies and high-volume creators.

### Includes
Everything in Studio, plus:
- **1,000 clips/month**
- 10 team members
- Priority processing
- Priority support
- Custom branding

---

## 🏢 Enterprise Plan

**Custom for:** Large organizations.

### Includes
Everything in Scale, plus:
- Custom clip limits
- Unlimited team members
- Dedicated account manager
- API access
- SLA guarantees

---

## 🔄 Changing Plans

### Upgrading

1. Go to **Settings → Billing**
2. Click **"Upgrade"**
3. Select new plan
4. Immediate access to new features

### Downgrading

1. Go to **Settings → Billing**
2. Click **"Change Plan"**
3. Takes effect at next billing cycle

## ❓ FAQ

**Q: Do unused clips roll over?**
A: No, clips reset each billing cycle.

**Q: Can I get a refund?**
A: Yes, within 7 days for first-time subscribers.

**Q: Can I pause my subscription?**
A: Not currently. Cancel and resubscribe when ready.
