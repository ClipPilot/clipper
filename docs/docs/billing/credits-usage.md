## 🎯 Overview

Credits are the currency of Cuttr. Different actions use different amounts.

## 📈 Tracking Usage

### Usage Dashboard

Access at **Settings → Usage**

See:
- Credits used this period
- Credits remaining
- Usage by feature
- Reset date

### Visual Indicators

| Indicator | Meaning |
|-----------|---------|
| 🟢 Green | Plenty remaining (over 50%) |
| 🟡 Yellow | Watch usage (25-50%) |
| 🔴 Red | Running low (under 25%) |

---

## 🔄 Credit Reset

- Credits reset on your billing date
- Unused credits don't roll over
- Full allocation available at reset

---

## ⚠️ When You Run Out

What happens:
- Can't save new clips
- Can't use UGC features
- Can still preview
- Can still edit existing clips

Your options:
1. Wait for reset
2. Purchase add-on credits
3. Upgrade plan

---

## 💡 Pro Tips

1. **Preview before saving** - Avoid wasted saves
2. **Check usage weekly** - No surprises
3. **Plan UGC carefully** - 5-10 credits is significant

---

## ❓ FAQ

**Q: Do unused credits roll over?**
A: No, credits reset each billing cycle.

**Q: Are there credit refunds?**
A: Failed generations are auto-refunded.

**Q: What counts as one clip?**
A: Each unique video you save = 1 clip credit.
