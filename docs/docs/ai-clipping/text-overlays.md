# Text Overlays

**What You'll Learn:**
- Add and position text overlays
- Customize fonts and colors
- Best practices for readability

---

## Overview

Text overlays add context, hooks, or calls-to-action to your clips. They appear as static or animated text on top of your video.

---

## Adding Text Overlays

### How to Add

1. Select your clip in the editor
2. Click **"Add Text"** button
3. Type your text
4. Position it on the preview

### Overlay Types

| Type | Best For |
|------|----------|
| **Hook Text** | Grab attention at start |
| **Title** | Topic introduction |
| **CTA** | Call-to-action at end |
| **Label** | Identify speakers |

---

## Customization Options

### Position

- **Top**: Headers, topic titles
- **Center**: Main focus text
- **Bottom**: CTAs, captions area

### Typography

| Setting | Options |
|---------|---------|
| Font | Multiple modern fonts |
| Size | Small, Medium, Large |
| Weight | Normal, Bold |
| Color | Full color picker |

### Background

- **None**: Text only
- **Box**: Solid background
- **Gradient**: Fading background

---

## Pro Tips

1. **Keep it short** - 3-5 words maximum
2. **High contrast** - Light text on dark, or vice versa
3. **Don't cover faces** - Position around the subject
4. **Match your brand** - Use consistent colors/fonts
