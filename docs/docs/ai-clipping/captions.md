# Captions

📌 **What You'll Learn:**
- Enable and customize captions
- Word-by-word animation styles
- Caption best practices

---

## 🎯 Overview

Captions are auto-generated from your video's audio. They display as animated text that follows the speaker, making your clips accessible and engaging.

---

## 🔛 Enabling Captions

### Toggle Captions

1. In the clip editor, find **"Captions"** toggle
2. Click to enable/disable
3. Preview updates in real-time

### Caption Generation

Captions are generated from the AI transcription:
- Automatic timing sync
- Word-by-word highlighting
- Punctuation included

---

## 🎨 Caption Styling

### Animation Styles

| Style | Effect |
|-------|--------|
| **Word Pop** | Each word pops in |
| **Highlight** | Active word highlighted |
| **Karaoke** | Words light up in sequence |
| **Fade** | Smooth fade between words |

### Visual Settings

| Setting | Options |
|---------|---------|
| **Font** | Multiple styles available |
| **Size** | Adjustable for readability |
| **Color** | Primary text color |
| **Highlight Color** | Active word color |
| **Background** | None, box, or blur |
| **Position** | Top, center, or bottom |

---

## ✏️ Editing Captions

### Fix Transcription Errors

1. Click on any caption line
2. Edit the text directly
3. Changes save automatically

### Adjust Timing

1. Select a caption segment
2. Drag start/end handles
3. Fine-tune sync with audio

---

## 💡 Pro Tips

1. **Always review captions** - AI isn't perfect
2. **Use high-contrast colors** - Ensure readability
3. **Position appropriately** - Don't block the subject
4. **Keep font size readable** - Test on mobile

---

## ❓ FAQ

**Q: Why are some words wrong?**
A: AI transcription can misinterpret accents, mumbling, or technical terms. Edit manually.

**Q: Can I add captions in other languages?**
A: Currently, Cuttr supports English captions. More languages coming soon.
