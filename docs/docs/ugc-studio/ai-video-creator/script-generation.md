# Script Generation

**What You'll Learn:**
- How AI writes your script
- Script structure and scene types
- Editing and customization

---

## Overview

The AI writes a complete UGC script based on your product info. It creates a structured narrative designed for social media engagement.

---

## Script Structure

### Scene Types

| Type | Description |
|------|-------------|
| **Hook** | Attention-grabbing opening (2-4s) |
| **Problem** | Relatable pain point (4-6s) |
| **Solution** | Introduce the product (4-6s) |
| **Demo** | Show it in action (3-5s) |
| **Testimonial** | Share the experience (4-5s) |
| **CTA** | Call to action (3-4s) |

### Shot Types

| Shot | What It Means |
|------|---------------|
| **A-Roll** | Character speaking to camera |
| **B-Roll** | Product shots, no character face |
| **Mixed** | Character visible but not addressing camera |

---

## Reviewing the Script

### What You'll See

For each scene:
- Scene type (hook, problem, etc.)
- Dialogue text
- Shot type (a-roll, b-roll)
- Estimated duration

### Making Edits

1. Click on any scene
2. Edit the dialogue text
3. AI regenerates that scene's visuals if needed

### What to Look For

Check for:
- Natural-sounding dialogue
- Accurate product claims
- Good flow between scenes
- Appropriate length

Watch out for:
- Generic or vague language
- Inaccurate information
- Too long or too short
- Unnatural phrasing

---

## Regenerating

Not happy with the script?

1. Click **"Regenerate Script"**
2. Get a fresh version
3. Repeat until satisfied

You can also regenerate individual scenes.

---

## Pro Tips

1. **Edit before generating** - Saves credits and time
2. **Keep hooks punchy** - First 2 seconds matter most
3. **Natural language** - Edit to sound conversational
4. **Check timing** - Total should be 20-45 seconds
