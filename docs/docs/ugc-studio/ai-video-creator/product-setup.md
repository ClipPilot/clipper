# Product Setup

**What You'll Learn:**
- Upload product images effectively
- Write compelling descriptions
- Set up for best results

---

## Overview

Product setup is the foundation of your AI video. Better inputs = better outputs.

---

## Product Images

### What to Upload

| Image Type | Purpose |
|------------|---------|
| **Hero shot** | Main product view |
| **Detail shots** | Close-up features |
| **Lifestyle** | Product in use |
| **Packaging** | Box or container |

### Image Requirements

| Requirement | Specification |
|-------------|---------------|
| Format | JPG, PNG, WebP |
| Min resolution | 512x512 |
| Max file size | 10MB per image |
| Recommended | 2-5 images |

### Tips for Better Images

**Do:**
- Use good lighting
- Show product clearly
- Include different angles
- Keep backgrounds clean

**Don't:**
- Use blurry photos
- Include text/watermarks
- Mix multiple products
- Use low resolution

## Product Description

### What to Include

1. **Product name** - Official or common name
2. **What it does** - Core function/benefit
3. **Key features** - 3-5 main selling points
4. **Target audience** - Who it's for
5. **Unique value** - What makes it different

### Example Description

```
Product: GlowSkin Vitamin C Serum

A powerful anti-aging serum with 20% vitamin C that
brightens skin and reduces dark spots.

Key features:
- 20% pure vitamin C
- Visible results in 2 weeks
- Suitable for all skin types
- Cruelty-free and vegan

Perfect for: Adults 25+ concerned about aging, dark spots, or dull skin.

Unique: Triple-action formula that brightens, firms, and hydrates.
```

---

## Pro Tips

1. **More context = better script** - Don't be brief
2. **Include benefits, not just features**
3. **Mention your target customer**
4. **Note any specific claims you can make**
