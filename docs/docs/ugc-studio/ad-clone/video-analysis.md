# Video Analysis

**What You'll Learn:**
- Upload reference videos
- Understand AI analysis results
- Review scene breakdowns

---

## Overview

Before cloning, AI analyzes your reference video to understand its structure, script, and flow.

---

## Uploading Reference

### Supported Sources

| Source | How |
|--------|-----|
| **File upload** | Drag and drop video file |
| **URL** | Paste video URL |

### Requirements

| Requirement | Specification |
|-------------|---------------|
| Length | 15 seconds - 2 minutes |
| Format | MP4, MOV, WebM |
| Quality | 480p minimum |
| Audio | Required for script extraction |

---

## Analysis Process

After upload, AI performs:

1. **Transcription** - Converts speech to text
2. **Scene Detection** - Identifies individual shots
3. **Structure Analysis** - Categorizes each scene
4. **Timing Extraction** - Notes durations

**Time:** 1-3 minutes

---

## Analysis Results

### Scene Breakdown

You'll see each scene with:

| Field | Description |
|-------|-------------|
| **Thumbnail** | Visual preview |
| **Type** | Hook, problem, solution, etc. |
| **Shot** | A-roll, b-roll, mixed |
| **Duration** | Length in seconds |
| **Dialogue** | Transcribed text |

### Example Output

```
Scene 1: Hook (A-roll, 3s)
"You won't believe what just happened..."

Scene 2: Problem (A-roll, 5s)
"I used to struggle with..."

Scene 3: Solution (B-roll, 4s)
"Then I discovered this game-changer..."
```

---

## Adjusting Analysis

AI isn't perfect. You can:

- **Edit scene types** - Recategorize if wrong
- **Fix transcription** - Correct text errors
- **Adjust timing** - Fine-tune boundaries
- **Merge/split scenes** - Combine or separate

---

## Pro Tips

1. **Clear audio = better transcription**
2. **Simple ads analyze better** - Complex edits are harder
3. **Review carefully** - Fix errors before generating
4. **Note the structure** - Learn from successful patterns
