# Creating Characters

**What You'll Learn:**
- Design AI characters step-by-step
- Customize appearance and style
- Select the best generated images

---

## Overview

AI Characters are the actors for your UGC content. Create realistic characters with customized appearance, outfits, and settings.

---

## Creation Steps

### Step 1: Basic Info

1. Go to **UGC Studio → Characters**
2. Click **"Create Character"**
3. Select **Gender**: Male or Female
4. Select **Age Range**: Young Adult, Adult, Middle-aged, etc.

### Step 2: Appearance

Configure physical features:

| Feature | Options |
|---------|---------|
| **Hair Color** | Blonde, Brown, Black, Red, etc. |
| **Hair Style** | Short, Medium, Long, various styles |
| **Skin Tone** | Light to Dark spectrum |
| **Eye Color** | Brown, Blue, Green, Hazel, etc. |
| **Body Type** | Slim, Athletic, Average, etc. |

### Step 3: Style

Set the look and environment:

| Setting | Examples |
|---------|----------|
| **Outfit** | Casual, Professional, Sporty, etc. |
| **Setting** | Home, Office, Outdoor, Studio |
| **Camera Style** | Close-up, Medium shot, etc. |

### Step 4: Generate

1. Click **"Generate Character"**
2. AI creates 4 image variations
3. Wait 30-60 seconds

### Step 5: Select & Save

1. Review the 4 generated images
2. Click on your favorite(s) to select
3. Enter a name for your character
4. Click **"Save Character"**

---

## Credits

- **Cost:** 1 credit per character generation
- Selecting images doesn't cost extra
- Failed generations are refunded

---

## Pro Tips

1. **Be specific** - Clear descriptions = better results
2. **Generate variations** - Create multiple versions
3. **Name clearly** - Use descriptive names like "Sarah_Professional"
4. **Check hands/fingers** - AI sometimes generates extra fingers

---

## FAQ

**Q: Can I edit a character after creation?**
A: You can create variations but can't edit existing images.

**Q: How many characters can I create?**
A: Unlimited, based on your credit balance.

**Q: Can I use real people's faces?**
A: No, characters are AI-generated. Use Face Swap for real faces.
