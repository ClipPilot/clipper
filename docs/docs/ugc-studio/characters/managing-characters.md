# Managing Characters

📌 **What You'll Learn:**
- View and organize your characters
- Create character variations
- Share with the community

---

## 🎯 Overview

Your character library stores all AI actors you've created. Manage, organize, and reuse them across projects.

---

## 📍 Character Library

### Accessing Characters

1. Go to **UGC Studio → Characters**
2. View all your created characters
3. Search by name

### Character Cards

Each card shows:
- Character image
- Name
- Creation date
- Usage count

---

## 🔄 Creating Variations

Want the same character in a different style?

1. Click on existing character
2. Select **"Create Variation"**
3. Modify style settings:
   - Different outfit
   - Different setting
   - Different pose
4. Generate new images
5. Save as new character

**Cost:** 1 credit per variation

---

## 🌐 Community Sharing

### Make Character Public

1. Open character details
2. Toggle **"Share with Community"**
3. Character appears in public gallery

### Use Community Characters

1. Browse **"Community"** tab
2. Click character you like
3. Add to your library
4. Use in your projects

---

## 🗑️ Deleting Characters

1. Open character
2. Click **"Delete"**
3. Confirm deletion

:::warning
Deleted characters cannot be recovered. Clips using them remain unaffected.
:::

---

## 💡 Pro Tips

1. **Name descriptively** - "Alex_Business_Suit" vs "Character 1"
2. **Create variations** - Same person, different looks
3. **Share winners** - Help the community
4. **Favorite often-used** - Quick access in projects
