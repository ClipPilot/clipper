# Auto-Detect Mode

📌 **What You'll Learn:**
- Let AI find faces automatically
- Review and adjust detections
- Handle multiple faces

---

## 🎯 Overview

Auto-detect mode uses AI to automatically find faces in your video, saving you time on manual segment definition.

---

## 📝 How to Use

### Step 1: Upload & Enable

1. Upload your video
2. Toggle **"Auto-Detect Faces"** on
3. Click **"Analyze"**

### Step 2: Review Detections

AI will identify:
- When faces appear
- Face positions
- Suggested segments

You'll see a timeline with detected face segments highlighted.

### Step 3: Adjust If Needed

- **Add missed segments** - AI might miss some
- **Remove false positives** - Delete unwanted detections
- **Merge segments** - Combine if same person

### Step 4: Assign Characters

1. Select each detected segment
2. Choose which character to use
3. Repeat for all segments

### Step 5: Generate

Click **"Generate"** to process all segments.

---

## ⚠️ Limitations

Auto-detect may struggle with:
- Extreme angles (looking away)
- Very fast movement
- Poor lighting
- Partially obscured faces
- Very small faces in frame

---

## 💡 Pro Tips

1. **Review all detections** - AI isn't perfect
2. **Use manual for precision** - When auto misses
3. **Works best with talking head** - Clear face visibility
4. **Multiple people** - Each gets separate segments
