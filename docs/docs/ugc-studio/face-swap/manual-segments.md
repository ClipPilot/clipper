# Manual Segments

📌 **What You'll Learn:**
- Define swap segments manually
- Set precise start/end times
- Handle multiple segments

---

## 🎯 Overview

Manual segment mode gives you precise control over which parts of your video get face-swapped.

---

## 📝 Step-by-Step

### Step 1: Upload Video

1. Go to **UGC Studio → Face Swap**
2. Upload your source video
3. Wait for processing

### Step 2: Add Segment

1. Click **"Add Segment"**
2. Set **Start Time** (when swap begins)
3. Set **End Time** (when swap ends)
4. Preview the segment

### Step 3: Select Character

1. Choose an AI character from your library
2. The character will replace the face in this segment

### Step 4: Repeat for Multiple Segments

If your video has multiple sections needing different characters:

| Segment | Start | End | Character |
|---------|-------|-----|-----------|
| 1 | 0:00 | 0:45 | Sarah |
| 2 | 1:20 | 2:00 | Alex |
| 3 | 2:30 | 3:00 | Sarah |

### Step 5: Generate

1. Review all segments
2. Click **"Generate"**
3. Wait for processing (20-40 min per segment)

---

## ⚙️ Segment Settings

### Timing Controls

| Control | Function |
|---------|----------|
| Start Time | Frame where swap begins |
| End Time | Frame where swap ends |
| Preview | See the selected frame |

### Best Practices

- Keep segments under 2 minutes for best quality
- Start/end at moments with clear face visibility
- Avoid starting mid-sentence (audio sync)

---

## 💡 Pro Tips

1. **Frame-by-frame** - Use arrow keys for precise timing
2. **Natural cuts** - Start/end at scene transitions
3. **Overlap handling** - Segments shouldn't overlap
4. **Same character** - Can use same character multiple times
